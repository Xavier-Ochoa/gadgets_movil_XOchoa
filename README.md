# 🎮 Venta de Videojuegos

Aplicación móvil desarrollada con **Ionic + Angular (Standalone)** y **Supabase** como backend. Permite gestionar un catálogo de videojuegos con operaciones CRUD completas: listar, crear, editar y eliminar. Cada videojuego puede mostrar una imagen mediante URL.

---

## 📸 Funcionalidades

- Listado de videojuegos con imagen, plataforma, categoría, precio y stock
- Formulario para crear y editar videojuegos
- Eliminación de registros
- Preview de imagen en tiempo real al ingresar una URL
- Imagen de fallback (🎮) cuando no hay URL cargada
- Conexión en tiempo real con base de datos Supabase

## 🗄️ Configuración de Supabase

### Paso 1 — Crear el proyecto

1. Ir a [https://supabase.com](https://supabase.com) e iniciar sesión
2. Hacer clic en **New Project**
3. Elegir nombre, contraseña de base de datos y región
4. Esperar a que el proyecto termine de inicializarse (~2 minutos)

### Paso 2 — Crear la tabla `videojuegos`

En el panel de Supabase ir a **SQL Editor** y ejecutar el siguiente script:

```sql
CREATE TABLE videojuegos (
  id        BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  titulo    TEXT        NOT NULL,
  plataforma TEXT       NOT NULL,
  precio    NUMERIC     NOT NULL DEFAULT 0,
  stock     INTEGER     NOT NULL DEFAULT 0,
  categoria TEXT,
  imagen_url TEXT
);
```

### Paso 3 — Configurar Row Level Security (RLS)

Por defecto Supabase bloquea todas las operaciones. Ejecuta esto para permitir acceso público (adecuado para desarrollo o proyectos académicos):

```sql
-- Habilitar RLS
ALTER TABLE videojuegos ENABLE ROW LEVEL SECURITY;

-- Permitir SELECT (leer)
CREATE POLICY "Permitir lectura pública"
ON videojuegos FOR SELECT
USING (true);

-- Permitir INSERT (crear)
CREATE POLICY "Permitir inserción pública"
ON videojuegos FOR INSERT
WITH CHECK (true);

-- Permitir UPDATE (editar)
CREATE POLICY "Permitir actualización pública"
ON videojuegos FOR UPDATE
USING (true);

-- Permitir DELETE (eliminar)
CREATE POLICY "Permitir eliminación pública"
ON videojuegos FOR DELETE
USING (true);
```

> 💡 Para proyectos en producción se recomienda restringir estas políticas con autenticación de usuario.

### Paso 4 — Obtener las credenciales

En el panel de Supabase ir a **Project Settings → API**:

- **Project URL** → copiar en `supabaseUrl`
- **anon / public key** → copiar en `supabaseKey`

## 🧩 Modelo de datos

```typescript
interface Videojuego {
  id?:         number;   // Autoincremental (Supabase)
  titulo:      string;   // Nombre del juego
  plataforma:  string;   // PS5, Xbox, PC, etc.
  precio:      number;   // Precio de venta
  stock:       number;   // Unidades disponibles
  categoria?:  string;   // Acción, RPG, Deportes, etc.
  imagen_url?: string;   // URL pública de la imagen
}
```
